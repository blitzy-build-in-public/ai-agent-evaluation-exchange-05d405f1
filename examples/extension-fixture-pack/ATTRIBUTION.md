# Attribution

## Credited to

This example extension is credited to the project handle `example-extension-maintainer`.

The credit is a project handle rather than a person because this repository carries no real
personal name, contact address or reference to a private project, product or dataset. The maintainer
record behind the handle lives with the project rather than in the repository, and a reviewer reads
this file under that same rule, as part of the manual review checklist in
`docs/REVIEW-CHECKLIST.md`.

## What a contributed extension declares

An extension contributed to this project declares its own license and credits its author.
Contributing an extension does not force disclosure of the contributor's own source code: the
maintainers review the declared license and the attribution that comes with a contribution, not the
contributor's private work. `CONTRIBUTING.md` describes the contribution path and the checklist a
contribution follows, and `docs/starter-tasks/` carries the brief for adding a fixture pack through
the `FixturePack` seam, which is the worked version of this example. This folder is that worked
example: `README.md` describes the pack it registers, `src/` implements the seam interface and
`fixtures/` holds the cases the pack adds.

## Fictional content

The fixture data, identifiers and wording in this folder are invented for the example and contain no
real brand, organisation, personal name or contact detail.
